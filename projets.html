// Guide de débogage

Les 6 Pièges Fréquents & Leurs Solutions

Si un objet réagit bizarrement, ton problème se trouve obligatoirement dans cette liste.

01

L'échelle est déformée lors du biseau (Bevel écrasé)

Cause : Tu as redimensionné l'objet en Mode Objet avec S sans appliquer l'échelle.
Fix : En Mode Objet, fais Ctrl+A → All Transforms (ou Apply Scale). L'échelle repassera à (1, 1, 1).

02

Le mesh apparaît invisible ou troué d'un côté dans Roblox

Cause : Les Normales (la direction extérieure des faces) sont inversées à l'envers.
Fix : En Mode Édition, appuie sur A (tout sélectionner) puis Maj+N (Recalculate Outside).

03

L'outil tourne autour d'un point bizarre dans la main du joueur

Cause : L'origine de l'objet (point orange) n'est pas située sur la poignée.
Fix : Déplace le mesh en Mode Édition pour aligner le centre de la poignée sur le point d'origine (0, 0, 0).

04

Les textures ou couleurs ne s'affichent pas dans Roblox

Cause : Les matériaux utilisent des nœuds Shaders complexes non exportables en FBX.
Fix : N'utilise que des matériaux simples avec une couleur unie dans Base Color ou déplie les UVs sur une palette 2D.

05

L'objet s'enfonce dans le sol ou traverse les murs dans le jeu

Cause : La boîte de collision de Roblox est réglée sur Box au lieu d'adapter la forme réelle.
Fix : Dans Roblox Studio, sélectionne le MeshPart et règle CollisionFidelity = PreciseConvexDecomposition.

06

Seule une moitié du mesh a été exportée

Cause : Le modificateur Mirror n'a pas été appliqué avant l'exportation.
Fix : En Mode Objet, survole le modificateur Mirror et appuie sur Ctrl+A pour l'appliquer définitivement avant l'export FBX.
