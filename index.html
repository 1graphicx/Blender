// Planning suggéré

Le planning pour devenir
autonome en 1 journée.

4 phases chronologiques pour progresser à ton rythme sans brûler les étapes.

9h00
Phase 1 — Découverte (9h–10h30)

Apprivoiser l'interface sans se noyer

Installation, tour de l'interface, navigation dans la vue 3D, sélection, et le geste fondateur de Blender : déplacer / tourner / redimensionner au clavier.

10h30
Phase 2 — Fondations (10h30–13h)

Modéliser en mode Édition + premier objet propre

Sommets, arêtes, faces, extrusion, boucles de sélection, modificateurs Subdivision Surface et Mirror. Tu montes ta première vraie scène.

14h00
Phase 3 — Armes, Habillage & Export (14h–16h30)

Création d'armes 3D, UV et export FBX

Modélisation d'armes dans l'Atelier 3D, dépliage UV pour textures, puis préparation du fichier FBX optimisé (échelle, orientation, pivot).

16h30
Phase 4 — Import & Integration Roblox (16h30–17h30)

Tes meshes dans Roblox Studio, prêts à jouer

Import du FBX via Import 3D, configuration des Tools/Handles, ajustement des couleurs et matériaux directement dans le moteur de jeu.
